# 模型管理

## 缩放并切片

**接口地址**:`/api/models/scaleAndSlice`

**请求方式**:`POST`

**请求数据类型**:`application/x-www-form-urlencoded,application/json`

**响应数据类型**:`*/*`

**接口描述**:<p>对3D模型进行等比例缩放（支持放大和缩小），然后进行切片，可选择自动打印。缩放后的尺寸不能超过机器规格（默认100mm×100mm×100mm）</p>

**请求示例**:

```javascript
{
  "modelIdOrUrl": "http://example.com/model.glb",
  "scaleFactor": 0.8,
  "addSupports": false
}
```

**请求参数**:

| 参数名称                     | 参数说明                                                                      | 请求类型 | 是否必须 | 数据类型                     | schema                       |
| ---------------------------- | ----------------------------------------------------------------------------- | -------- | -------- | ---------------------------- | ---------------------------- |
| modelScaleAndSliceRequestDTO | 模型缩放并切片打印请求参数                                                    | body     | true     | ModelScaleAndSliceRequestDTO | ModelScaleAndSliceRequestDTO |
| &emsp;&emsp;modelIdOrUrl     | 模型ID或模型文件URL                                                           |          | true     | string                       |                              |
| &emsp;&emsp;scaleFactor      | 缩放因子（> 0，< 1为缩小，> 1为放大，= 1为不变，如0.5=缩小50%，2.0=放大200%） |          | true     | number(double)               |                              |
| &emsp;&emsp;addSupports      | 是否添加支撑结构                                                              |          | false    | boolean                      |                              |

**响应状态**:

| 状态码 | 说明 | schema                           |
| ------ | ---- | -------------------------------- |
| 200    | OK   | ResultModelScaleAndSliceResponse |

**响应参数**:

| 参数名称            | 参数说明 | 类型                       | schema                     |
| ------------------- | -------- | -------------------------- | -------------------------- |
| code                |          | integer(int32)             | integer(int32)             |
| msg                 |          | string                     |                            |
| data                |          | ModelScaleAndSliceResponse | ModelScaleAndSliceResponse |
| &emsp;&emsp;taskId  |          | string                     |                            |
| &emsp;&emsp;success |          | boolean                    |                            |
| &emsp;&emsp;message |          | string                     |                            |

**响应示例**:

```javascript
{
	"code": 0,
	"msg": "",
	"data": {
		"taskId": "",
		"success": true,
		"message": ""
	}
}
```
